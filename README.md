# PhonePe Pulse – Data Analysis Dashboard

## Overview
The PhonePe Pulse Dashboard is a comprehensive data analytics project designed to explore and visualize India's digital payment landscape. Using interactive dashboards built in Power BI, this project delivers actionable insights into transaction trends, user growth, and regional performance across states and districts.

The objective is to transform raw transactional data into meaningful business insights that support data-driven decision-making.

---

## Key Features

### Geo Analysis
- Interactive map visualizing transaction distribution across India  
- State-wise comparison of transaction values  
- Identification of top-performing districts  
- Dynamic filtering by Year, Quarter, State, and District  

### User Insights
- Analysis of registered user growth over time  
- Top states and districts by user base  
- Mobile brand usage distribution  
- Trend analysis across multiple time periods  

### Transaction Analysis
- Top 10 states by transaction value  
- Top 10 districts by transaction value  
- Category-wise transaction performance:
  - Peer-to-peer payments  
  - Merchant payments  
  - Recharge and bill payments  
  - Financial services

## Insights Derived

- High transaction volumes are concentrated in states such as Telangana, Karnataka, and Maharashtra  
- Peer-to-peer payments represent the largest share of total transactions  
- Significant growth in user adoption is observed after 2020  
- Urban districts contribute disproportionately to transaction value
